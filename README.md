# aayushadhikari7.github.io

Personal portfolio built with Astro.

## Features

- Dark/light mode toggle
- Project filtering by language
- Search (Cmd/Ctrl + K)
- Scroll animations
- Custom cursor
- Typewriter effect
- Back to top button
- Responsive design
- SEO optimized

## Tech Stack

- [Astro](https://astro.build) - Static site generator
- Vanilla JS - No framework bloat
- CSS Variables - Theming

## Development

```bash
npm install
npm run dev
```

## Deployment

Automatically deploys to GitHub Pages on push to `main`.
